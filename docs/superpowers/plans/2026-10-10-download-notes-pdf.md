# Implementation Plan: Export Generated Notes as Printable PDF

Add a direct, tactile **"Export PDF"** button to the generated study notes action bar in the Document Workspace that invokes a tailored, publication-ready print layout (`window.print()`).

---

### User Decisions & Requirements Confirmed
- **Format:** Clean Printable PDF via browser print stylesheet (`window.print()`).
- **UI Trigger:** Direct single-click button `"Export PDF"` placed in the note action bar alongside the `"Copy"` and `"Regenerate"` controls.
- **Printed Document Content:** Clean document header (Title, source type badge, date, read time, Source.io watermark) + structured notes markdown content only. All UI controls (top dock, capsule bar, action buttons, AI feedback, outlines, chat copilot) are hidden during print.

---

### Architecture & Technical Strategy

1. **Print Stylesheet (`@media print` in `app/globals.css`):**
   - Provide `@media print` rules that:
     - Reset body background to pure white `#FFFFFF` and text to `#0F172A` / `#1E293B` regardless of whether dark mode is active (ensuring crisp ink-friendly contrast and zero background toner waste).
     - Hide all workspace chrome (`header`, `nav`, `aside`, `.no-print`, dock, left rail, floating capsule tab bar, AI feedback widgets, modals, scrollbars).
     - Target the print-specific container (`#printable-notes-section` or `.printable-notes-container`), ensuring proper margin (`@page { margin: 18mm 15mm; }`), clean page breaks for headings (`h1, h2, h3 { page-break-after: avoid; break-after: avoid; }`), and table wrapping (`table, pre, blockquote { page-break-inside: avoid; break-inside: avoid; }`).
     - Render KaTeX equations and code blocks with clean borders and contrast.

2. **Dedicated Printable Document Header:**
   - In `DocumentWorkspace.tsx`, wrap the printed note with a print-only header:
     - Document Title (`h1`)
     - Formatted creation date & read time
     - Source Type badge (e.g. `PDF`, `AUDIO`, `YOUTUBE`)
     - Subtle "Generated by Source.io Study Engine" footer/header.

3. **"Export PDF" Action Button in `DocumentWorkspace.tsx`:**
   - Place a sleek tactile pill button with a `Printer` icon next to `"Copy"`:
     - Icon: `Printer` (Lucide)
     - Label: `Export PDF`
     - Action: Calls `window.print()` safely.
